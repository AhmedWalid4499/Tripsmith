# Fonts for generated images

Used by `opengraph-image.tsx` (Satori needs raw font data; it reads `.woff`, not `.woff2`).

- `fraunces-latin-600-normal.woff`: Fraunces, SIL Open Font License 1.1, from `@fontsource/fraunces@5.3.0`
- `geist-sans-latin-{400,500}-normal.woff`: Geist, SIL Open Font License 1.1, from `@fontsource/geist-sans@5.3.0`
